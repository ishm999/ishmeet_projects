Case study

VIN Decoder + AI Vehicle Description Workflow

A Google Sheets workflow that decoded VINs, structured attributes, and used Claude to generate branded descriptions in bulk.

Description cell

Context

Large inventories and vendor platforms can make merchandising copy repetitive and hard to keep consistent. Staff also should not have to prompt an LLM one vehicle at a time.

Problem

Create a spreadsheet-based way to decode vehicle data and generate brand-consistent descriptions in bulk.

Constraints

  • Usable by non-technical staff inside Google Sheets
  • No heavy infrastructure
  • Structured rows and columns
  • Separate actions for VIN decoding and brand-tone description generation

Workflow architecture

Two menu actions run the workflow: decode VINs, then generate descriptions from the structured rows.

Custom menu

Adds spreadsheet actions staff can run without leaving Google Sheets.

Decode VIN option

Sends VIN rows to the NHTSA API and returns factual vehicle attributes.

NHTSA attributes

Loads decoded vehicle details back into structured columns, giving the AI step clean inputs.

Generate description option

Runs a second menu action that prepares the description request after vehicle data has been structured.

Brand tone

Provides Claude with tone, formatting, and description requirements so the copy fits the intended brand style.

Description cell

Writes the generated vehicle description back into the sheet, keeping each unit organized by row.

My role

Built the Apps Script workflow, connected NHTSA VIN decoding, structured the Sheet, and added separate menu actions for decoding and Claude-powered description generation.

Outcome / value

  • Reduced manual merchandising work
  • Structured vehicle data for bulk copy
  • Improved brand-tone consistency
  • Kept the workflow inside Google Sheets

What I learned

AI worked best after the factual data was structured. NHTSA handled attributes; Claude handled brand-tone description formatting.
