VIN Decoder + AI Vehicle Description Workflow

A lightweight Google Sheets and Apps Script workflow that used the NHTSA VIN Decoder API and Claude to generate vehicle descriptions in bulk with structured attributes and a consistent brand tone.

Tools used

Google Sheets Google Apps Script NHTSA VIN Decoder API Claude API Structured prompts
Custom menu
Decode VIN option
NHTSA attributes
Generate description
Claude + brand tone
Description cell

Context

Automotive brands and dealer groups can work with large inventory volumes, expensive vendor platforms, and recurring merchandising tasks. Staff also should not have to manually paste vehicle details into an LLM chat one unit at a time just to create usable descriptions.

Problem

The workflow needed a structured way to decode vehicle information, prepare consistent inputs, and generate descriptions in bulk while keeping brand tone and formatting consistent across rows.

Constraints

  • Needed to be usable by non-technical users
  • Needed to fit into a familiar spreadsheet workflow
  • Needed to avoid heavy infrastructure
  • Needed to keep outputs structured by row and column
  • Needed separate actions for decoding VINs and generating descriptions
  • Needed to support a repeatable brand tone instead of one-off chat outputs

Workflow architecture

The spreadsheet has two separate menu actions: one to decode VINs into structured data, and another to generate branded descriptions from that data.

Custom menu

Adds spreadsheet actions staff can run without leaving Google Sheets.

Decode VIN option

Sends VIN rows to the NHTSA API and returns factual vehicle attributes.

NHTSA attributes

Loads decoded vehicle details back into structured columns, giving the AI step clean inputs.

Generate description option

Runs a second menu action that prepares the description request after vehicle data has been structured.

Brand tone

Provides Claude with tone, formatting, and description requirements so the copy fits the intended brand style.

Description cell

Writes the generated vehicle description back into the sheet, keeping each unit organized by row.

My role

Designed and built the workflow logic using Google Apps Script, connected the NHTSA VIN Decoder API, structured the spreadsheet layout, and created separate custom menu actions for VIN decoding and Claude-powered description generation with brand-tone prompt structure.

Outcome / value

  • Reduced repetitive manual merchandising work
  • Made vehicle information easier to structure
  • Created a more consistent description generation process
  • Supported bulk description creation without manually using LLM chat for each vehicle
  • Made brand tone easier to apply consistently across inventory copy
  • Kept the workflow accessible inside a tool staff already understood

What I learned

AI outputs are much more useful when the input data is structured first. The workflow worked best when the NHTSA API handled factual vehicle attributes, the spreadsheet organized the source data, and the Claude layer handled brand-tone formatting and description generation.
