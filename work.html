Inventory data automation

Inventory Scraper & Data Distribution Workflow

Context

Inventory data is often locked behind older systems, FTP feed processes, vendor approvals, or API access requests. This workflow used public inventory pages as the source for a feed-like data table.

Workflow

Daily scheduled Make run -> clear Sheet -> Firecrawl map -> code filters inventory URLs -> iterator -> JSON extraction -> VIN validation -> Google Sheet rows with photo links for distribution.

Tools

Make.com, Firecrawl API, Google Sheets, JavaScript/code modules, JSON parsing, iterator, LLM-assisted prompt and code support.
