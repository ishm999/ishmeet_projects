Case study

Automated Inventory Video Script & Voiceover Workflow

A Make workflow that turns vehicle-page details into multiple video scripts and voiceover files for non-technical staff.

Tools used

Make.com Claude API ElevenLabs Email automation Webhooks Prompt design
Vehicle details email
Webhook trigger
3 Claude styles
ElevenLabs voices
Email response

Context

Dealers create videos for unique inventory units, especially pre-owned vehicles where condition, color, options, and trim matter. The challenge was scaling scripts after the vehicle expert was no longer available.

Problem

Vehicle-page details already existed, but staff still needed a way to turn them into useful scripts without being product experts.

Constraints

  • Simple email trigger for non-technical staff
  • Works from pasted vehicle-page details
  • Returns scripts and MP3s quickly
  • Keeps token use, prompts, and quality manageable

Workflow architecture

A near-real-time Make workflow turns vehicle-page details into three script styles, voiceovers, and an email response in under a minute.

Vehicle page details

The team pastes existing vehicle information from the website into the email body.

Webhook trigger

The email starts the Make workflow, so staff do not need to open or understand the automation itself.

Claude branches

The workflow routes into three script styles, each with branded tone, video structure, walkaround guidance, length, and format requirements.

ElevenLabs voices

Each script branch is converted into a voiceover file using ElevenLabs.

Email response

The sender receives the scripts and MP3 files back by email in a near-real-time loop, typically under a minute.

My role

Designed the Make flow, wrote prompts for three video styles, connected Claude and ElevenLabs branches, and tested output quality.

Outcome / value

  • Reduced manual scripting effort
  • Created three reusable script styles
  • Supported 250+ videos over time
  • Returned scripts and MP3s in about 30-60 seconds
  • Kept human review in the loop

What I learned

The three script styles came from staff feedback. The workflow improved when automation, review, and real-world testing stayed connected.
